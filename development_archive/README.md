# 开发归档

这里收录曾放在本地归档和实验输出目录中的开发资料，方便查阅与复现思路：

- `legacy/`：历史 Python / C# 源码、测试、配置、示例地图、阶段性文档及旧版可执行文件。
- `experiments/`：历次实验与交接时保存的源码快照、脚本和文字报告。
- `root_executables/`：项目根目录中两份备用构建产物的快照。

以上均是历史材料，不参与现行构建或自动测试，也不保证独立运行。旧文档中的结论、相对路径和指向本机输出的链接可能已过时或失效；以项目根目录的当前源码和 README 为准。旧版程序仅供研究，日常使用请重新构建当前版本。

归档源码中的个人微信缓存目录已改为通过 `WECHAT_APPLET_PACKAGES` 环境变量指定。原始运行输出、抓包会话、证书私钥、桌面截图、本机虚拟环境和第三方游戏包未纳入；本目录不含完整实验原始数据，历史报告中的结果应按当时记录理解。
