## 生成新的基准

输出目录必须是新目录，避免覆盖样本和混入历史答案。源地图必须是普通牌完整地图，且各牌型数量为三的倍数。

```powershell
.\venv\Scripts\python.exe truth_benchmark.py generate `
  --source output\auto_capture\sessions\20261029T050434Z-887207\map_1.json `
  --original output\auto_capture\sessions\20261029T025403Z-7a9fb8\map_1.json `
  --output output\truth_benchmark_new --count 20 --seed 20261029
```

默认生成20张植入图、20张均匀重排图，并额外加入源图和指定原图。所有图保持相同几何布局和牌型总数。

植入图使用槽上限4、5、6格，以及随机、偏挖深、偏展开三种合法取牌顺序。通关见证单独保存，工作进程不接收见证、生成种子、样本标签、提示、固定路线或冲突缓存。

## 固定协议运行

```powershell
.\venv\Scripts\python.exe truth_benchmark.py run `
  --dataset output\truth_benchmark_new --seconds 10 --parallel 12 --memory-mb 1536
```

默认比较原项目Python normal、原生tight-top、静态束搜索balance和CP-SAT cumulative。每种算法均单路，每次10秒求解预算；墙钟时间、CPU时间、工作集和私有内存峰值另行记录。

`--solvers` 可选择算法子集，例如 `--solvers tight_top static_beam cp_sat`。

运行中 `progress.json`、`summary.json`、`REPORT.md` 与 `report.html` 持续更新。HTML在运行期间每5秒重新读取页面，完成后停止自动刷新。

同协议再次运行会核对源代码/二进制SHA、地图SHA和协议后跳过已完成的测试；不会把旧答案输入求解器。修改源代码或协议后，需使用新的实验目录。

要停止实验，在对应数据集目录创建名为 `STOP` 的文件。程序会终止自己启动的工作进程并保留已完成的结果。确认停止后移除该文件，可用原协议继续尚未完成的任务。

## 如何读结果

- `solved`：完整路线通过两个回放器，不是最深候选。
- `unknown`：预算或资源限制内未得到结论。
- `model_unsat` / `unsat_claim`：模型或算法报告无解，但没有独立证书时不作为已知负标签。
- `contradiction`：已验证植入见证存在，但算法声称无解；实验停止并保留现场。
- `error`：工作进程失败或候选非法。

随机图的可解比例下界按“至少一个算法给出合法完整解”的地图数计算，同一图不会按算法重复计数。未经独立证实的负标签不收紧上界。生成分布也不等于游戏服务器实际出题分布。
