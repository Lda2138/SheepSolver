## 准备好的改动

`seed_export_hook.py prepare` 已在项目输出目录生成一个补丁包，并通过完整回读、资源逐项对比和 Node.js 语法检查。**目前未安装到微信。**

它只改动本机该游戏 500 版本脚本包里的一个成功返回分支：在游戏已解密并成功取得真实种子后，调用原生文件 API 写出 `sheepsolver_seed.json`，其中仅包括四个种子数、请求种子标识、返回标识和时间。原来的返回值保持一致。

安装会改变微信小程序缓存里的 `_subpackages_script-bundle_.wxapkg`。它需要重新打开小程序，然后开始新一局，因此不能倒回补录当前局的种子。微信是否接受改过的包尚未实测；如果完整性检查拒绝或客户端重新下载了包，这条导出路径可能不生效。工具不会修改完整性校验规则。

## 恢复和接入

- 安装前保存原包，并记录原包与补丁的 SHA256。
- `seed_export_hook.py restore` 在确认当前仍是补丁包时恢复原始字节；若微信已经更新包，保留更新版本。
- `seed_export_support.py` 只读游戏用户目录的导出文件，以本局请求标识和时间筛选，拒绝旧局种子。
- `capture_with_seed_export.py` 将该文件监听接入现有地图抓取器；种子到齐后继续使用原项目洗牌和求解。

命令（仅在同意安装之后执行）：

```powershell
.\venv\Scripts\python.exe seed_export_hook.py install
.\venv\Scripts\python.exe seed_export_hook.py restore
```

备份与改动清单：`output/seed_export_hook/manifest.json`。准备过程未写入游戏安装目录。
