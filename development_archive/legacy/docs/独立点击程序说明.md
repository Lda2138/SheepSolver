# 独立点击与框选程序

启动 `SheepClicker.exe`。这是本机 C# / Windows Forms 程序，不依赖 Codex 的电脑操控工具，也不需要额外安装依赖。

## 功能

- 实时截图预览，直接在微信牌面上显示红框与下一次点击标签。
- 默认用 Windows 后台鼠标消息点击，不切换前台窗口、不移动鼠标。此机器的当前微信版本已实测接受该消息，并完成一组玉米消除。
- 可选前台鼠标输入模式。需要你手动把微信切回前台后按 F8；程序不会自行抢焦点。
- 点击前等待、重新核对目标，再发送输入；点击后检查目标区域是否变化。没有变化立即暂停。
- 自动匹配当前可见的青草、胡萝卜和玉米，优先补齐牌槽的三张。未知牌槽或无可见配对时暂停，不猜隐藏牌。
- 在截图中点击牌面可以建立手动队列；可保存标注图、坐标计划和动作日志。
- 导入计划前匹配截图指纹，拒绝把旧截图坐标或仓库示例答案直接套用到当前游戏。
- 已处理当前显示缩放及窗口阴影边距；微信移动或改变尺寸时，执行中的点击会取消。

## 操作

1. 打开微信游戏，保持窗口未最小化。
2. 启动 EXE，程序自动连接唯一的 `羊了个羊：星球` 窗口并截图，默认尚未点击。
3. 点“只标注下一张”查看红框；点“执行一步”或“连续执行 / 暂停”发送点击。
4. F8 暂停/继续，F9 或按住 Esc 停止。关闭程序也会取消未发送的点击。
5. 无法自动匹配时，在预览图中选择目标，按单步执行。点击区域限定于棋盘，不选择道具或菜单。

主界面首次显示时不请求激活。若全局 F8/F9 被其他程序占用，可用窗口中的按钮。Esc 在执行期间由程序每 50 毫秒检查。

## 命令行

```powershell
# 只截图与识别，不点击
.\SheepClicker.Diagnostics.exe --capture

# 独立程序画框并发送一次后台点击，然后保存前后截图与验证日志
.\SheepClicker.Diagnostics.exe --background-step

# 后台连续匹配，最多执行 24 次；遇到不确定状态提前停止
.\SheepClicker.Diagnostics.exe --background-auto 24

# 对保存截图进行识别与变化检测测试，不发送鼠标输入
.\SheepClicker.Diagnostics.exe --self-test

# 从源码重新编译
.\build_clicker.ps1
```

输出保存在 `output`：`click_actions.jsonl`、`程序点击标注.png`、`程序点击计划.json`、当前截图，以及后台测试的前后截图与 JSON。

## 能力范围

这是可实际点击和画框的独立程序。当前自动图像匹配只覆盖三种已采样图案；它的可见配对策略不等同于 SheepSolver 对完整地图进行回溯求解，不能保证复杂第二关通关。完整地图、隐藏牌类型和当前牌槽状态仍是整局可靠求解所需的数据。

区域变化检测只是确认牌面发生变化；不会把动画变化宣称为已经通关。程序从不自动提交通关接口，也不读取账号令牌或修改系统代理、证书。

核心源码为 `SheepClicker.cs`。模板保存在 `output/tutorial_after_first_click.png` 和 `output/clicker_reference.png`，请与 EXE 一起保留。
# 完整地图答案后台执行器

新增 `SolverPlayback.exe`，接入当前局真实地图与原项目求解答案，支持全部 15 种普通牌。`SheepClicker.exe` 的旧三种图案自动模式仍用于独立诊断；正式通关使用完整答案执行器。

执行器每步先显示无焦点、可穿透的红框，再发送后台点击，并检查目标图案、窗口位置、牌面变化和牌槽数量。Esc/F9 停止，F8 暂停或继续。不会移动系统鼠标或自动切换窗口。校准截图与棋盘不一致时拒绝开始。

当前局的 `output/auto_capture/sessions/<局号>/main_play/` 包含：

- `plan.json`：原答案牌编号到窗口坐标的映射。
- `reference.png`：该局开局校准截图。
- `next_click.png`：当前目标红框图。
- `last_verified.png`：最近核对的实际牌面。
- `actions.jsonl`：每步牌编号、图案类型、坐标、牌槽数量和画面变化。
- `playback_status.json`：当前进度与停止原因。

`make_solver_plan.py` 生成坐标计划；只有经规则回放验证的完整答案可执行。窗口位置或尺寸改变会停止；新的一局需要新的地图、答案和校准截图。不要直接把旧计划用于新棋盘。
